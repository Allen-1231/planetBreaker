# 星球粉碎者 (Planet Breaker)

第一人稱太空戰鬥機網頁遊戲：在真實軌道上追擊九顆行星，並對抗戰鬥機、太空梭、戰艦與巨型戰艦。

## 檔案
- `index.html`：頁面結構（選單、HUD、結算畫面）
- `css/style.css`：樣式
- `js/main.js`：遊戲主程式（軌道、戰鬥、敵人、強化、操作、音效）
- `js/textures.js`：行星貼圖（base64，體積大，很少需要改動）

## 執行
直接雙擊 `index.html` 即可，或用 GitHub Pages 發佈。需要網路（three.js r160 與 Google Fonts 從 CDN 載入）。

## 操作
滑鼠瞄準（點擊後鎖定游標）／左鍵射擊／右鍵或 E 炸彈／W S 前進減速／A D 或 ←→ 平移／Space 上升／C 下降／Shift 加速／F 全螢幕。
